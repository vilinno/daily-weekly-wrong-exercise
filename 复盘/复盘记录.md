# 复盘记录

本文件由本人填写，自动化只读取，不会改写。每次阅读笔记、完成复盘或核对掌握度测试后追加一行；提交到 Git 后，记录才会进入下一次复盘统计。

## 填写规则

- `日期`：北京时间日期，格式为 `YYYY-MM-DD`。
- `来源`：优先填写题图的仓库相对路径；整篇阅读或复盘时也可填写 Markdown 笔记路径。
- `动作`：只能填写 `阅读`、`复盘` 或 `测试`。
- `结果`：可填写 `完成`、`未完成`、`正确`、`部分掌握`、`错误` 或 `已掌握`。
- `正确率`：测试时可填写 `0` 至 `100` 的数字；其他动作可留空。
- `备注`：记录遗忘点、仍不确定的条件或下次需要重点检查的内容。
