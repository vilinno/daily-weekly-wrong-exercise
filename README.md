# 每日错题

这是一个用于记录考研备考过程中错题、重难点题目和阶段性复习材料的本地知识库。

## 项目目标

做题时，将做错或值得反复复习的题目截图放入 `过渡站/`。根据题目的知识点、题型、解题方法和特殊提醒为图片命名，再把图片移动到对应科目的 `assets/` 目录。当天结束后，在对应科目目录的 Markdown 笔记中完成最终归纳。

Markdown 只保留题目的知识点、使用的方法和特殊注意事项；完整的计算、推导和思路复盘保存在手写草稿中，不要求在本仓库重复记录。

## 目录结构

```text
.
├── 过渡站/                         # 题目截图的临时放置区
├── 数学/
│   ├── 高等数学/
│   │   ├── assets/                 # 高等数学题图
│   │   └── *.md                    # 按知识点整理的归纳笔记
│   └── 线性代数/
│       ├── assets/
│       └── *.md
├── 408/
│   └── assets/
├── 复盘/
│   └── 复盘记录.md                   # 本人填写的阅读、复盘和测试记录
├── 报告/
│   ├── 每日/
│   ├── 每周/
│   ├── 复盘/                         # 状态追踪、掌握度测试和独立答案
│   └── 纠错/                         # 逐篇笔记审校结果
├── README.md                       # 项目说明
└── AGENTS.md                       # 项目基线与长期维护准则
```

科目和知识层级可以按备考需要继续增加。图片的最终归属是对应科目的 `assets/`，Markdown 通常放在该科目或知识模块目录下。

## 日常使用方式

1. 将题目截图放入 `过渡站/`。
2. 使用稳定、可检索的中文名称重命名图片，名称尽量体现“知识点 - 题型 - 方法 - 特殊提醒”。
3. 将图片移动到对应科目的 `assets/` 目录。
4. 在对应的 Markdown 笔记中插入题图，并补充知识点、使用方法和特殊注意事项。
5. 检查图片链接和 Markdown 内容，使用 Git 提交当天新增或修改的资料。

建议使用相对路径引用图片，例如在 `数学/高等数学/无穷级数.md` 中使用：

```markdown
![题目说明](assets/无穷级数-级数收敛定义（部分和）-放缩.png)
```

如果使用 Obsidian 插入图片，笔记也可能保存为 `![[文件名.png]]` 或带尺寸的 `![[文件名.png|640x480]]`。自动化会识别这两种图片引用，并把题图关联到实际所在的 Markdown 笔记。

## Git 记录约定

Git 是每日资料变更的时间线。初始化提交会保存当前已有的题图和笔记；之后每次整理完当天内容，都应提交一次，使新增题目、题图移动和笔记修改可以被准确识别。

推荐的提交信息格式：

```text
daily: YYYY-MM-DD
weekly: YYYY-Www
docs: 简短说明
```

提交前应先查看 `git status` 和 `git diff`，确认没有误删、误移或把不属于本项目的文件加入提交。

## 自动化工作流（已实现）

自动化实现位于 [`自动化/`](F:/软件数据/系统桌面/每日错题/自动化/)，当前约定为：

- 每天北京时间 22:30，只读取已经提交且 message 为 `daily: YYYY-MM-DD` 的内容，生成 `报告/每日/日报-YYYY-MM-DD.md`。
- 每周日北京时间 08:00，分别为数学和 408 生成约 10 题的周测及独立答案核验文件。
- 周测总结过去 7 天的题型和方法，并通过来源编号链接到对应题图和 Markdown。
- 检查题图链接、孤立题图、提交 message 和来源编号，但不自动修复。
- `review` 命令读取 `复盘/复盘记录.md`，追踪阅读、复盘、测试和掌握状态，优先对到期或薄弱错题生成测试题；题目与答案分开保存。
- `correct` 命令逐篇结合笔记全文和原始题图审校，在纠错报告中标明位置、错误原因和建议正确说法；所有 AI 纠错均标记为待人工确认，不自动改写笔记。
- 自动化采用分层模块结构；`自动化/main.py` 仅作为命令行入口，日报、周测、复盘和纠错分别由独立工作流模块实现。

自动化只生成文件，不修改原始题图和 Markdown，也不自动提交 Git。首次启用前需要配置有效的 OpenAI API 密钥，并按 [`自动化/README.md`](F:/软件数据/系统桌面/每日错题/自动化/README.md) 注册 Windows 定时任务。

## 当前数据边界

本项目记录的是题目截图和简要归纳，不等同于完整解题档案。手写草稿不在仓库中时，自动化只能依据仓库可见内容进行统计和出题；任何无法从题图或 Markdown 确认的信息，都应明确标注为待确认，而不是自行补全。
