# 每日错题

这是一个用于记录考研备考过程中错题、重难点题目和阶段性复习材料的本地知识库。

## 项目目标

做题时，将做错或值得反复复习的题目截图放入 `过渡站/`。根据题目的知识点、题型、解题方法和特殊提醒为图片命名，再把图片移动到对应科目的 `assets/` 目录。当天结束后，在对应科目目录的 Markdown 笔记中完成最终归纳。

Markdown 只保留题目的知识点、使用的方法和特殊注意事项；完整的计算、推导和思路复盘保存在手写草稿中，不要求在本仓库重复记录。

## 目录结构

```text
.
├── 过渡站/                         # 题目截图的临时放置区
├── 数学/
│   ├── 高等数学/
│   │   ├── assets/                 # 高等数学题图
│   │   └── *.md                    # 按知识点整理的归纳笔记
│   └── 线性代数/
│       ├── assets/
│       └── *.md
├── 408/
│   └── assets/
├── README.md                       # 项目说明
└── AGENTS.md                       # 项目基线与长期维护准则
```

科目和知识层级可以按备考需要继续增加。图片的最终归属是对应科目的 `assets/`，Markdown 通常放在该科目或知识模块目录下。

## 日常使用方式

1. 将题目截图放入 `过渡站/`。
2. 使用稳定、可检索的中文名称重命名图片，名称尽量体现“知识点 - 题型 - 方法 - 特殊提醒”。
3. 将图片移动到对应科目的 `assets/` 目录。
4. 在对应的 Markdown 笔记中插入题图，并补充知识点、使用方法和特殊注意事项。
5. 检查图片链接和 Markdown 内容，使用 Git 提交当天新增或修改的资料。

建议使用相对路径引用图片，例如在 `数学/高等数学/无穷级数.md` 中使用：

```markdown
![题目说明](assets/无穷级数-级数收敛定义（部分和）-放缩.png)
```

## Git 记录约定

Git 是每日资料变更的时间线。初始化提交会保存当前已有的题图和笔记；之后每次整理完当天内容，都应提交一次，使新增题目、题图移动和笔记修改可以被准确识别。

推荐的提交信息格式：

```text
daily: YYYY-MM-DD
weekly: YYYY-Www
docs: 简短说明
```

提交前应先查看 `git status` 和 `git diff`，确认没有误删、误移或把不属于本项目的文件加入提交。

## 自动化规划（当前尚未上线）

计划中的自动化包括：

- 每日晚间扫描当天 Git 变更和错题 Markdown，生成当日错题统计与知识点汇总。
- 每周根据已有笔记抽取测试范围，并生成来源可追溯的测试题和标注清晰的变式题。
- 在生成前检查题图链接、孤立题图、重复命名和未整理的 `过渡站/` 文件。

自动化在获得审阅批准前不会创建或启动定时任务。具体的执行时刻、输出目录、模型调用方式和是否自动提交，见后续评审后的工作流方案。

## 当前数据边界

本项目记录的是题目截图和简要归纳，不等同于完整解题档案。手写草稿不在仓库中时，自动化只能依据仓库可见内容进行统计和出题；任何无法从题图或 Markdown 确认的信息，都应明确标注为待确认，而不是自行补全。
