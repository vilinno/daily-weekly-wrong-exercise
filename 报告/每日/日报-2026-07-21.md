- **Cache 缺失时的总延迟计算**：Cache 未命中时需考虑发送地址和读命令的时延、存储器准备数据的时延、总线传输数据的时延（来源：[S004](../../408/assets/cache缺失时的内存读取.png)）

- **程序局部性分析**：通过分析嵌套循环中变量和数组的访问模式，判断时间局部性和空间局部性（来源：[S005](../../408/assets/for循环程序的局部性分析.png)）

- **令牌环网络的性质辨析**：判断信道利用率、重负载下利用率、节点持有令牌的时间、无数据时令牌处理等命题的正误（来源：[S006](../../408/assets/令牌环网络的相关命题.png)）

- **信道划分 MAC 协议（FDM/TDM）的辨析**：FDM 频分复用和 TDM 时分复用的利用传输能力差异及实际应用原因（来源：[S007](../../408/assets/信道划分MAC的辨析.png)、[S009](../../408/assets/时分复用中介质和信号的相关性质.png)）

- **存储系统的地址访问**：CPU 在高速缓存、主存、硬盘构成的三级存储系统中直接使用的地址类型（来源：[S008](../../408/assets/存储系统的地址.png)）

- **组相联映射中比较器的个数和位数**：给定 Cache 数据区大小、主存块大小、映射方式，计算比较器个数和位数（来源：[S010](../../408/assets/组相联映射中的比较器.png)）

- **Cache 行位数计算**：给定主存地址位数、Cache 数据区大小、主存块大小、映射方式、写策略，计算 Cache 行的位数（包含标记、有效位、脏位等）（来源：[S011](../../408/assets/规定映射方式和写命中策略时的cache地址.png)）

## 使用的方法

- **Cache 容量公式法**：根据映射方式确定标记位数、块内偏移位数，结合数据位、有效位、脏位计算总容量（来源：[S003](../../408/assets/cache容量计算.png)、[S011](../../408/assets/规定映射方式和写命中策略时的cache地址.png)）

- **时延分解法**：将 Cache 缺失的总时间分解为命令发送、存储器准备、数据传输三个阶段，分别计算周期数后相加（来源：[S004](../../408/assets/cache缺失时的内存读取.png)）

- **循环迭代展开法**：通过手动展开嵌套循环的前几次迭代，观察变量和数组元素的重复访问和连续访问情况，判断局部性（来源：[S005](../../408/assets/for循环程序的局部性分析.png)）

- **比较器配置计算**：组相联映射时，比较器个数等于每组的路数，比较器位数等于标记位数（来源：[S010](../../408/assets/组相联映射中的比较器.png)）

- **Cache 行结构分析**：根据写策略确定是否需要脏位（回写需要，全写/写直达不需要），根据映射方式确定标记位数，计算行的总位数（来源：[S011](../../408/assets/规定映射方式和写命中策略时的cache地址.png)）

## 特殊注意事项

- 主存块大小并非越大越好，存在最优值，过大会降低 Cache 利用率并增加缺失率（来源：[S002](../../408/assets/cache大小、主存块大小和cache缺失率的关系.png)）

- Cache 缺失延迟需要累加所有阶段，不能遗漏命令发送和地址发送的时延（来源：[S004](../../408/assets/cache缺失时的内存读取.png)）

- 嵌套循环的内层变量（如 `j`）和被累乘/累加的变量（如 `temp`）通常具有时间局部性；连续访问数组元素具有空间局部性（来源：[S005](../../408/assets/for循环程序的局部性分析.png)）

- 令牌环网络中，节点只能在固定时间段内持有令牌，无论是否有数据要发送（来源：[S006](../../408/assets/令牌环网络的相关命题.png)）

- TDM 适用于数字传输，FDM 适用于模拟传输；计算机网络多使用 TDM 是因为能更充分利用带宽（来源：[S007](../../408/assets/信道划分MAC的辨析.png)）

- CPU 直接使用虚拟地址（或逻辑地址），而非物理地址或磁盘地址（来源：[S008](../../408/assets/存储系统的地址.png)）

- TDM 介质的带宽（频率范围）必须大于所有信号带宽之和，而非单个信号的带宽（来源：[S009](../../408/assets/时分复用中介质和信号的相关性质.png)）

- 组相联映射中，比较器个数等于组内的路数（路数 = Cache 块数 / 组数），而非组数（来源：[S010](../../408/assets/组相联映射中的比较器.png)）

- 直接映射方式不需要脏位的说法待确认；回写（Write Back）策略必须配备脏位以标识块是否被修改（来源：[S011](../../408/assets/规定映射方式和写命中策略时的cache地址.png)）
