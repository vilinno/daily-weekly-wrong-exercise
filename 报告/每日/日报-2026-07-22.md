## 知识点与题型

- **向量组的秩与线性相关性判定**：四个三维向量的线性表示与秩的关系，利用秩的不等式 $r(\alpha_1,\alpha_2) < r(\alpha_1,\alpha_2,\alpha_3)$ 推导极大线性无关组，判断能否线性表示（来源：[[数学/线性代数/assets/向量-向量组的秩推知向量组的线性相关性.png|S001]]）

- **矩阵的初等变换与秩的等价性**：通过 $r(\alpha_1,\alpha_2,\alpha_3) = r(\alpha_1,\alpha_2,\alpha_3,\alpha_4)$ 判定向量线性表示的标准定义式（来源：[[数学/线性代数/assets/向量-向量组的秩推知向量组的线性相关性.png|S001]]）

- **正定实对称矩阵的判定**：$A^T A$ 的正定性及其与单位矩阵相加后的相似性质，利用正定矩阵可开方的特性（来源：[[数学/线性代数/assets/矩阵-判定正定实对称矩阵.png|S002]]）

- **矩阵的秩与初等变换的适用条件**：行满秩矩阵应右乘可逆矩阵 P，列满秩矩阵应左乘可逆矩阵 Q（来源：[[数学/线性代数/assets/矩阵-判定正定实对称矩阵.png|S002]]）

- **正交矩阵的乘积性质**：正交矩阵 A、B 的乘积 AB 仍为正交矩阵，但和 A+B 一般不是正交矩阵（来源：[[数学/线性代数/assets/矩阵-正交矩阵性质证明.png|S003]]、[[数学/线性代数/assets/矩阵-正交矩阵的变换.png|S004]]）

- **正交矩阵的特征值**：利用 $A^T A \alpha = \lambda^2 \alpha$ 推导正交矩阵特征值必为 ±1，转置矩阵特征值与特征向量不变（来源：[[数学/线性代数/assets/矩阵-正交矩阵性质证明.png|S003]]、[[数学/线性代数/assets/矩阵-正交矩阵的变换.png|S004]]）

- **正交矩阵的行列式性质**：$|A+B| = -|A+B|$ 推导出 $|A+B| = 0$，即两个正交矩阵之和不可逆（来源：[[数学/线性代数/assets/矩阵-正交矩阵性质证明.png|S003]]、[[数学/线性代数/assets/矩阵-正交矩阵的变换.png|S004]]）

- **正交矩阵保持向量范数与正交性**：正交矩阵不改变向量的第二范数，且保持向量间的正交关系（来源：[[数学/线性代数/assets/矩阵-正交矩阵性质证明.png|S003]]、[[数学/线性代数/assets/矩阵-正交矩阵的变换.png|S004]]）

- **数列极限的证明**：调和级数与对数的关系，将 $\ln(1+n)$ 转化为积分 $\int_1^{n+1} \frac{1}{x} dx$，再利用积分区间可加性转换为和式（来源：[[数学/高等数学/assets/无穷级数-作差证收敛.png|S005]]，这是对已有题目的复盘补充）

## 使用的方法

- **逆否命题法**：由"$\alpha_4$ 不能被线性表示"推出"$\alpha_{1-3}$ 线性相关"（来源：[[数学/线性代数/assets/向量-向量组的秩推知向量组的线性相关性.png|S001]]）

- **秩的不等式分析**：通过 $r(\alpha_1,\alpha_2) < r(\alpha_1,\alpha_2,\alpha_3)$ 和 $r(\alpha_2,\alpha_3) < r(\alpha_4,\alpha_2,\alpha_3)$ 讨论得到极大线性无关组（来源：[[数学/线性代数/assets/向量-向量组的秩推知向量组的线性相关性.png|S001]]）

- **排除法**：在无法直接推导时，通过排除其他选项确定答案（来源：[[数学/线性代数/assets/向量-向量组的秩推知向量组的线性相关性.png|S001]]、[[数学/线性代数/assets/矩阵-正交矩阵性质证明.png|S003]]、[[数学/线性代数/assets/矩阵-正交矩阵的变换.png|S004]]）

- **正交矩阵定义式验证**：利用 $AA^T = E$ 或 $(AB)(AB)^T = E$ 直接验证正交性（来源：[[数学/线性代数/assets/矩阵-判定正定实对称矩阵.png|S002]]、[[数学/线性代数/assets/矩阵-正交矩阵性质证明.png|S003]]、[[数学/线性代数/assets/矩阵-正交矩阵的变换.png|S004]]）

- **特征值等式推导**：从 $A\alpha = \lambda\alpha$ 出发，结合 $A^T A = E$ 推导特征值的取值范围（来源：[[数学/线性代数/assets/矩阵-正交矩阵性质证明.png|S003]]、[[数学/线性代数/assets/矩阵-正交矩阵的变换.png|S004]]）

- **行列式的转置与相似变换**：通过 $|B^T A A^T + B^T B A^T| / (|A^T||B^T|)$ 推导行列式性质（来源：[[数学/线性代数/assets/矩阵-正交矩阵性质证明.png|S003]]、[[数学/线性代数/assets/矩阵-正交矩阵的变换.png|S004]]）

- **积分形式转换**：将对数函数转化为积分形式，再利用积分区间可加性统一为和式（来源：[[数学/高等数学/assets/无穷级数-作差证收敛.png|S005]]）

- **单调有界定理**：证明数列收敛性（来源：[[数学/高等数学/assets/无穷级数-作差证收敛.png|S005]]）

- **夹逼准则**：结合 $x_n$ 的形式变形求极限（来源：[[数学/高等数学/assets/无穷级数-作差证收敛.png|S005]]）

## 特殊注意事项

- **初等变换的方向性**：列变换对应右乘矩阵，$BA$ 形式无法按广义矩阵变换消除；行满秩右乘、列满秩左乘，不可混淆（来源：[[数学/线性代数/assets/矩阵-判定正定实对称矩阵.png|S002]]）

- **正交矩阵和的非正交性**：正交矩阵的积保持正交性，但和一般不保持正交性，$AA^T + AB^T + BA^T = O$ 无法继续推导（来源：[[数学/线性代数/assets/矩阵-正交矩阵性质证明.png|S003]]、[[数学/线性代数/assets/矩阵-正交矩阵的变换.png|S004]]）

- **转置矩阵的特征值与特征向量**：转置矩阵的特征值与特征向量与原矩阵相同，需在推导中明确运用（来源：[[数学/线性代数/assets/矩阵-正交矩阵性质证明.png|S003]]、[[数学/线性代数/assets/矩阵-正交矩阵的变换.png|S004]]）

- **相似性的传递性**：正定实对称矩阵相似于正的对角矩阵，相似具有传递性（来源：[[数学/线性代数/assets/矩阵-判定正定实对称矩阵.png|S002]]）

- **秩相等与线性表示的等价性**：$r(\alpha_1,\alpha_2,\alpha_3) = r(\alpha_1,\alpha_2,\alpha_3,\alpha_4)$ 是线性表示的标准判定式（来源：[[数学/线性代数/assets/向量-向量组的秩推知向量组的线性相关性.png|S001]]）

- **积分转和式的技巧**：对数函数可转化为 $\frac{1}{x}$ 的积分，积分区间可加性可将积分统一为和式形式（来源：[[数学/高等数学/assets/无穷级数-作差证收敛.png|S005]]）

## 知识点与题型

**计算机组成原理 - 存储系统**
- Cache容量计算：涉及块内地址、cache行数、标记位、脏位和有效位的计算，需掌握直接映射方式下各部分位数的推导（来源：[[408/assets/规定映射方式和写命中策略时的cache地址.png|S001]]）
- 多模块存储器效率最大化：低位交叉存储中，当存储体数≥存取周期与总线传输周期之比时，利用率达到100%（来源：[[408/assets/低位交叉中如何安排模块数量以使存储效率最大化.png|S002]]、[[408/assets/多模块存储器提高读取速度的原理.png|S003]]）
- 多模块存储器提速原理：通过独立读写电路实现，高位交叉采用并发，低位交叉采用流水线技术（来源：[[408/assets/低位交叉中如何安排模块数量以使存储效率最大化.png|S002]]、[[408/assets/多模块存储器提高读取速度的原理.png|S003]]）
- 存储系统地址访问：CPU使用虚拟地址访存，通过硬件机制访问cache和硬盘，CPU不直接感知cache和硬盘的存在（来源：[[408/assets/存储系统的地址.png|S004]]）

**计算机网络 - 数据链路层**
- 令牌环网络特性：空闲时信道仍有令牌帧流动；重负载下冲突率为0；节点获得令牌后修改状态位发送数据；无数据节点不能持有令牌（来源：[[408/assets/令牌环网络的相关命题.png|S005]]）
- 时分复用（TDM）实现条件：介质位速率需大于单个信号位速率，介质带宽需大于结合信号带宽（来源：[[408/assets/时分复用中介质和信号的相关性质.png|S008]]）
- 数据链路层协议功能：提供组帧、节点间可靠传输、流量控制；隐藏物理传输细节属于物理层功能（来源：[[408/assets/数据链路层协议功能.png|S007]]）
- TDM与FDM辨析：TDM适用于数字信号传输，FDM适用于模拟信号传输，因TDM抗干扰能力和整形能力更强（来源：[[408/assets/信道划分MAC的辨析.png|S006]]）
- 差错控制机制：信道质量好时仅检错，质量差时检错+纠错；检错方法有奇偶校验码和循环冗余校验；纠错使用海明编码（来源：[[408/assets/数据链路层差错控制中的海明距离.png|S009]]、[[408/assets/数据链路层防止帧丢失的方法.png|S010]]）
- 帧丢失防护方法：帧编号防重复，循环冗余检验检错，海明码纠错，计时器超时重发防帧丢失（来源：[[408/assets/数据链路层防止帧丢失的方法.png|S010]]）
- GBN协议大题：标注为待复习的流量控制综合题（来源：[[408/assets/数据链路层差错控制GBN协议大题.png|S011]]）

## 使用的方法

**存储系统计算**
- Cache容量计算三步法：先算块内地址位数（根据块大小），再算cache行数位数（cache容量÷块大小），最后用总地址位数减去前两者得标记位，附加控制位（脏位、有效位）（来源：[[408/assets/规定映射方式和写命中策略时的cache地址.png|S001]]）
- 多模块存储器配置：根据存取周期T与总线周期t的比值T/t确定最优存储体数（来源：[[408/assets/低位交叉中如何安排模块数量以使存储效率最大化.png|S002]]、[[408/assets/多模块存储器提高读取速度的原理.png|S003]]）

**数据链路层差错控制**
- 海明编码计算：使用公式 2^k ≥ k+l+1，其中k为纠错码位数，l为数据长度，+1表示无差错状态（来源：[[408/assets/数据链路层差错控制中的海明距离.png|S009]]）
- 码距判定：通过两编码异或后1的数量确定海明距离；检测d位错误需码距d+1，纠正c位错误需码距2c+1（来源：[[408/assets/数据链路层差错控制中的海明距离.png|S009]]）

**网络协议分析**
- 令牌环机制：节点获得令牌后将数据附加到令牌帧并修改状态位形成数据帧发送（来源：[[408/assets/令牌环网络的相关命题.png|S005]]）
- GBN协议分析：需结合时序图分析发送窗口、确认序号、超时重发等机制（来源：[[408/assets/数据链路层差错控制GBN协议大题.png|S011]]，待完成）

## 特殊注意事项

- Cache回写法必须设置脏位，每个cache行的总位数需加上脏位和有效位（来源：[[408/assets/规定映射方式和写命中策略时的cache地址.png|S001]]）
- CPU访存地址类型存在争议：通常使用虚拟地址，但需明确是否有虚拟存储系统；CPU通过硬件机制访问cache，对其透明（来源：[[408/assets/存储系统的地址.png|S004]]）
- 海明编码是个人易错点，需强化记忆码距与检错/纠错能力的关系公式（来源：[[408/assets/数据链路层差错控制中的海明距离.png|S009]]）
- 奇偶校验码只能校验奇数个错误，不能纠错（来源：[[408/assets/数据链路层差错控制中的海明距离.png|S009]]）
- 数据链路层可靠传输与传输层端到端可靠传输的区别：前者是节点间，后者是端到端（来源：[[408/assets/数据链路层协议功能.png|S007]]）
- TDM的"带宽"指信号的频率范围，与"位速率"（每秒传输二进制位数）不同（来源：[[408/assets/时分复用中介质和信号的相关性质.png|S008]]）
- 令牌环重负载优势：严格互斥访问使冲突率为0（除故障外），大幅提升信道利用率（来源：[[408/assets/令牌环网络的相关命题.png|S005]]）
